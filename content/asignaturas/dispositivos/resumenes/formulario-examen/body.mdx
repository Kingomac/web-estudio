<h2 id="tema-1">Tema 1 · Sensores</h2>

<div class="table-scroll">

| Magnitud | Fórmula |
| --- | --- |
| Campo de medida y salida | $S = X_{\max} - X_{\min} \qquad \mathrm{FSO} = Y_{\max} - Y_{\min}$ |
| Sensibilidad | $\dfrac{\mathrm{FSO}}{S}$ |
| Error a fondo de escala | $\varepsilon_{\mathrm{FS}} = \dfrac{\varepsilon_a}{S}$ |
| Fracción del FSO usada | $\dfrac{\text{excursión}}{\mathrm{FSO}}$ |
| Puente de Wheatstone | $V_o = V_A \dfrac{R_1}{R_1 + R_4} - V_A \dfrac{R_2}{R_2 + R_3}$; equilibrio $\dfrac{R_1}{R_4} = \dfrac{R_2}{R_3}$ |
| Inversor y no inversor | $-\dfrac{R_2}{R_1} \qquad 1 + \dfrac{R_2}{R_1}$ |
| Diferencial simétrico | $V_o = \dfrac{R_2}{R_1} (V_2 - V_1)$ |
| Instrumentación | $G = 1 + \dfrac{2 R_1}{R_g} \qquad \mathrm{CMRR} = \dfrac{A_d}{A_c}$ |
| Acondicionamiento | $V_o = G V_s + D$: $G = \dfrac{\Delta V_o}{\Delta V_s}$, $D = V_{o,\min} - G V_{s,\min}$ |
| ADC: códigos y LSB | $N = 2^n \qquad \mathrm{LSB} = \dfrac{\mathrm{FS}}{2^n}$ |
| ADC: resolución exacta | $\dfrac{\mathrm{FS}}{N - 1}$ |
| ADC: error y código | error $\pm \dfrac{\mathrm{LSB}}{2}$; código $= \dfrac{V_i}{\mathrm{LSB}}$ |
| Nyquist | $f_s \ge 2 f_{\max}$ |

</div>

<h2 id="temas-4-5">Temas 4 y 5 · Alimentación y energy harvesting</h2>

<div class="table-scroll">

| Magnitud | Fórmula |
| --- | --- |
| Carga | $Q = I\, t = C\, \Delta V$ |
| Energía del condensador | $E = \tfrac{1}{2} C \left(V_1^2 - V_2^2\right)$ |
| Condensador necesario | $C = \dfrac{2E}{V_1^2 - V_2^2} = \dfrac{Q}{\Delta V}$ |
| Energía consumida | $E = V_{\text{media}}\, I\, t$ |
| Convertidor | $P_{\text{sal}} = \eta\, P_{\text{ent}} \qquad t_{\text{carga}} = \dfrac{E}{P_{\text{sal}}}$ |
| Adaptación de carga | $P = \dfrac{V_{\mathrm{oc}}^2}{4R}$ |
| Capacidad de la batería | $\mathrm{mAh} \cdot 3{,}6 = \mathrm{C}$ |
| Solar | $P = \text{irradiancia} \cdot \text{área} \cdot \text{rendimiento}$ |
| Piezo | $V_p = \dfrac{I_p}{\omega C_p} \qquad P_{\max} = C_p f V_p^2$ |
| Piezo, medio puente | vacío $2V_p$, MPP $V_p$ |
| Piezo, onda completa | vacío $V_p$, MPP $V_p/2$; con interruptor ×2, SSHI ×4 |
| Peltier | $V = S_E\, \Delta T - I R_E$ |
| Peltier, hoja de datos | $R_E = \dfrac{V}{I}$ (con $\Delta T = 0$) $\qquad S_E = \dfrac{\Delta V}{\Delta T} \qquad R_T = \dfrac{\Delta T_M}{P_M}$ |
| Célula solar | $I_L \parallel$ diodo $\parallel R_p$, con $R_s$ en serie: $I = I_L - I_0 \left(e^{V/V_T} - 1\right) - \dfrac{V}{R_p}$ |

</div>
